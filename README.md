## 🚀 Key Features

* **🕷️ Stealth Puppeteer Scraper & Multi-Page Crawler:** Deep layout extraction, computed colors ranking, typography scale, DOM tree slicing, CSS variables, and API network interception.
* **⚡ Multi-Model AI Streaming Engine (SSE):** Real-time code generation powered by **Anthropic Claude 3.7 Sonnet**, **OpenAI GPT-4o**, **DeepSeek V3/R1**, and **Google Gemini 2.5**.
* **⚛️ In-Browser Live React 18 & Babel Standalone Sandbox:** Real JSX/React runtime with instant state re-rendering, Lucide React icon proxy, and dynamic Tailwind CSS compilation.
* **🔑 BYOK (Bring Your Own Key) Security:** Client-side AES-256 encrypted API key vault.
* **🚀 1-Click Cloud Deployment:** Direct integration with **GitHub REST API** (auto repo creation + tree commits) and **Vercel REST API v13** (instant edge preview URLs).
* **📦 Next.js 15 App Router Project Packager:** Generates ready-to-run `.zip` archives with zero build errors.
* **💳 LemonSqueezy / Stripe Billing:** Tier management, credit deduction, and webhook lifecycle guards.
* **💾 Persistent Database:** Embedded JSON storage engine with $O(1)$ indexed CRUD operations.

## 🛠️ Tech Stack

* **Backend:** Node.js, Express.js, Puppeteer-Core, AdmZip, Server-Sent Events (SSE).
* **Frontend:** Vanilla JS (ESNext), Tailwind CSS (Play CDN), Babel Standalone, React 18 UMD, FontAwesome 6.5.
* **Supported Framework Targets:** React 19 + Tailwind, Next.js 15 + Shadcn UI, Vue 3 SFC, Svelte 5 Runes, Vanilla HTML.

## 📦 Installation & Quick Start

1. **Clone the repository:**
   ```bash
   git clone https://github.com/<your-username>/siteprompter-ai.git
   cd siteprompter-ai
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Launch the server:**
   ```bash
   npm start
   ```

4. **Open in browser:**
   ```
   http://localhost:3000
   ```
